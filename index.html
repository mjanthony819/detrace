    Honest scope: Detrace simulates an educational model inspired by Raft - it is not production Raft and not formally verified. Scenarios marked INJECTED BUG deliberately mutate the model so the monitors have something to catch; they are not claims about real Raft. The replay guarantee is narrow and tested: one config (seed + faults + schedule + bug mode) always reproduces the identical trace and digest. Importing a recording replays its recorded config with this engine build and compares digests - a match is replay agreement, not a proof about any other engine or about real distributed systems. Run comparison reports the first trace event where two configs diverge under this engine; it does not prove two configs equivalent.
